📌 Executive Summary
The PISDOE Project is a strategic initiative designed to future-proof a Tier-1 Iron Ore asset in the Hamersley Basin, Western Australia. By integrating a 120MW Solar PV Array and a 50MWh BESS (Battery Energy Storage System), the project aims to reduce Scope 1 & 2 emissions by 45% while significantly lowering the C1 Cash Cost of production.

This repository serves as a professional portfolio for a Data-Driven Project Manager, showcasing technical depth in financial modeling, risk mitigation, and operational transition within the Australian mining landscape.
